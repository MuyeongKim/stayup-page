# 메인 랜딩페이지 보완 디자인

## 방향

메인 포털의 첫인상을 추상적인 기술 디렉터리에서 실제 현장을 보여주는 공공 안전 드론 포털로 전환한다. 시각 방향은 **현장 브리핑을 닮은 절제된 산업·에디토리얼 스타일**이다. 기존 네이비와 Orbitron 포인트는 유지하되, 기술 회사 같은 장식보다 전북소방 대원의 실제 활동 사진, 명확한 정보 위계, 구체적인 상태 표시를 우선한다. 첫 화면은 Stay-Up의 재난 대응을 중심축으로 삼고 FireHawks를 정밀 조종 역량을 확장하는 팀으로 연결해 두 팀이 한 포털에 존재하는 이유를 설명한다.

기존의 비대화형 `Portal Directory`는 제거하고 부안 내변산 수색 사진과 현장 캡션으로 교체한다. 주요 행동은 팀 소개, 최근 활동으로 한정한다. 팀 카드의 구조는 유지하되 이미지별 초점과 하단 그라데이션을 조정해 현수막과 본문이 경쟁하지 않게 한다. 두 팀 소개 다음에는 기존 JSON 데이터에서 최신 활동 세 건을 불러오는 섹션을 추가한다. 데이터 로딩 실패 시에는 오류 문구와 전체 활동 기록 링크를 남겨 탐색 경로가 끊기지 않게 한다.

프로젝트 영역은 실제 연결이 확인된 AI 객체탐지를 큰 운영 서비스 카드로 제시한다. 404가 확인된 RFID 업무 서비스는 활성 링크를 노출하지 않고 “연결 점검” 상태로 전환해, RAG 챗봇·음성 전사와 함께 압축된 개발 로드맵에서 안내한다. 모바일에서는 헤더와 여백을 줄이고, 활동·서비스 카드를 한 열로 쌓으며, 현장 사진의 높이와 캡션을 압축한다. 푸터에는 팀, 활동 기록, 서비스 바로가기를 추가해 페이지가 갑자기 끝나는 느낌과 신뢰 정보 부족을 보완한다.

## 접근성과 오류 처리

- 현장 사진에는 구체적인 대체 텍스트와 캡션을 제공한다.
- 활동 로딩 상태는 `role="status"`와 `aria-live`로 알린다.
- 외부 서비스는 새 창임을 링크 문구와 접근성 레이블에 모두 표시한다.
- JavaScript가 비활성화되거나 데이터 요청이 실패해도 전체 활동 기록 링크는 유지한다.
- `prefers-reduced-motion`에서는 기존과 동일하게 애니메이션을 사실상 비활성화한다.
