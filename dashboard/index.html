별도 모니터 · 표출 화면

모아 놓은 상황을 봅니다.

표출 화면 열기로 새 창을 띄워 모니터로 옮깁니다. 다른 PC나 휴대폰과 자동으로 공유하는 방식은 아닙니다.

보는 거리에 맞게

핵심 정보는
더 크게 봅니다.

기본 · 전체 정보는 상세를 함께 보여주고, 원거리 · 핵심 정보는 판정·위험 기체·지도·현재 우선 지시를 크게 배치합니다.

필요한 상세정보는 조작 패널에 남습니다. 실제 시청 위치에서 글자와 경보가 읽히는지 확인하세요.

한 상황을 함께 읽기

흩어진 정보를
같은 맥락으로.

현장에서 확인한 사실을 입력하고,
상황의 변화와 기록을 함께 살펴봅니다.

드론
기체 상태, 배터리와 확인시각, 담당구역, 조종·관측 담당을 정리합니다. 기체의 실제 상태를 자동으로 수신하지 않습니다.
인원
참여자의 역할과 투입·교대 시각을 관리하고, 조종 인원과 기체의 관계를 확인합니다.
수색구역
지도 이미지 위에 격자를 두고 상태와 담당을 표시합니다. 최종목격·발견 위치도 지도에 남길 수 있습니다.
기록
발생시각을 기준으로 활동을 남기고 정정·취소합니다. JSON으로 백업하거나 활동일지를 복사해 보관합니다.

처음 사용하는 순서

파일 하나로 시작하고,
백업으로 마무리합니다.

별도의 연습용 브라우저 프로필에서 샘플 상황으로 먼저 익혀보세요. 기존 기록이 있다면 샘플을 넣기 전에 JSON을 내보내세요.

  1. 01

    파일 받기

    프로그램 ZIP을 내려받고 압축을 풉니다. 폴더 안의 stayup-dash.html을 찾으세요.

  2. 02

    Chrome·Edge로 열기

    HTML 파일을 브라우저로 열면 조작 패널이 나타납니다. 별도 설치나 서버 실행은 필요하지 않습니다.

  3. 03

    표출 화면 연결

    표출 화면 열기를 누르고 새 창을 모니터로 옮깁니다. 경보음 준비로 시험음과 스피커도 확인하세요.

  4. 04

    종료 전 JSON 백업

    JSON 내보내기를 누른 뒤 실제 파일이 만들어졌는지 확인합니다. 브라우저 저장과 별개로 파일을 보관하세요.

표출 창이 열리지 않으면 팝업 차단 안내를 확인하세요. 두 창은 같은 PC·같은 브라우저 프로필에서 사용합니다.

사용 전에 알아두세요.

훈련·시연용
현재 훈련·시연 및 개발 검증용이며 실출동 단독 운용 승인 전입니다. 실제 현장 지휘나 비행 판단을 대신하지 않습니다.
입력한 정보의 표출
자동 기체 연동·자동 탐지·자동 비행 기능은 없습니다. 배터리를 포함한 기체 상태는 직접 확인해 입력합니다.
오프라인 중심
파일 실행과 입력·표출은 인터넷 없이 사용합니다. 선택적인 기상 자동 조회에는 인터넷이 필요하며 현장 좌표가 전송됩니다.
브라우저 저장과 백업
내용은 사용한 브라우저에 저장됩니다. PC·브라우저·프로필을 바꾸기 전과 사용 종료 전에는 JSON을 따로 보관하세요. 클라우드 공유는 제공하지 않습니다.

처음에는 샘플 데이터로 PC·브라우저·스피커·듀얼 모니터의 연결을 확인하세요.
